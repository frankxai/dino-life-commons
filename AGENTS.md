# AGENTS.md — Dino Life Commons

## Before writing content

1. Prefer real paleontology sources (Paleobiology Database, peer-reviewed papers, museum pages, Britannica).
2. Mark science-sensitive pages `status: needs-expert-review`.
3. Label all AI media as concept reconstruction in frontmatter + UI.
4. Never present generated soft-tissue color or behavior as proven fact.

## Media

- Prefer Grok Build CLI native Imagine for hero quality matching the viral demo.
- Always write/update `public/media/species/media-job.json` for batches.
- Re-verify species anatomy after generation (wrong animal mislabel has happened).

## Stack

Next.js App Router + Tailwind v4 + gray-matter + marked. Keep dependencies lean (storage-constrained host).
